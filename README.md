# PomKita front end

This project contains the PomKita front end in SvelteKit.

## Development

Install the pinned dependencies, then start the development server:

```sh
npm install
npm run dev
```

## Validation

Run the required checks before handoff:

```sh
npm run check
npm test
npm run build
```

Run `npm run test:e2e` for the Playwright project. The project uses Chromium only.
